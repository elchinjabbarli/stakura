# art/

Original brand assets for Stakura.

- `icon-1024.png` — master app icon (1024x1024). Original artwork created for
  Stakura (AI-assisted draft, curated and owned by the project author).
  `tools/icons.mjs` derives every shipped size from it (192/512/maskable/
  apple-touch/favicon + the og.png banner).

No third-party or licensed artwork is used anywhere in this game.
